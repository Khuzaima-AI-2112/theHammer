# Backend URL Configuration Update

I have updated the extension to allow you to manually paste your Cloud Run URL instead of relying on the hardcoded default.

### 1. UI Unlocked
- Removed the `readonly` attribute from the Backend URL input field in `popup.html`.
- Updated the tooltip to let developers know they can paste their custom backend URL here.

### 2. Save Logic Updated
- Modified the `settingsSaveBtn` click handler in `popup.js`.
- It now captures the value from the URL input, performs basic validation to ensure it starts with `http`, and saves it to `chrome.storage.local` as `cloudRunUrl`.

### How to Test
1. Reload the extension in `chrome://extensions/`.
2. Open the extension popup and click the **⚙ Settings** button.
3. You will now be able to click into the **Backend URL** field.
4. Paste your Cloud Run URL (e.g. `https://thehammer-backend-xyz-nn.a.run.app/api`).
5. Click **Close Settings** (which acts as the save button).
6. Click **Sign In** and it will launch the auth flow against your new custom backend!
