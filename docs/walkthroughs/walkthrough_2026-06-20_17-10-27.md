# Sprint 10: Extension Superpowers - Walkthrough

Here is a summary of the implemented features for Sprint 10:

## 10.1 Context Engine (Auto-tagging)
- Updated `service-worker.js` to automatically extract the context from the `tab.url` and `tab.title` during capture.
- Identifies common tools such as Figma, Jira, GitHub, Google Docs, Linear, and Notion.
- Automatically extracts ticket IDs (e.g. `PROJ-123`) from Jira and Linear titles and sets the `session.tool` appropriately.

## 10.2 Right-Click Element Capture
- Created an `offscreen.html` and `offscreen.js` document for the Chrome extension to handle background canvas operations.
- Updated `manifest.json` to include `"contextMenus"` and `"offscreen"` permissions.
- Added a Context Menu item "Hammer: Capture this element" that sends a message to `content.js`.
- `content.js` tracks the last right-clicked element and calculates its exact coordinates.
- Sends the element bounding box coordinates back to the service worker, which sends it to the offscreen document for cropping.

## 10.3 Admin Feature Entitlements
- Added `allowPreUploadBlur` and `instantClipboardLinks` to the `serializeUser` function in `backend/src/routes/admin/users.js`.
- Updated `PATCH /admin/users/:userId` to support the new entitlement fields.
- Exposed these new properties via `GET /config` in `backend/src/routes/admin/me.js`.
- Modified `portal/index.html` to add a new "Features" column in the admin users table to toggle these settings per user.

## 10.4 Pre-Upload Privacy Blur
- When `allowPreUploadBlur` is enabled for the user, triggering a capture presents a full-screen overlay over the page.
- The user can click and drag over sensitive areas of the screenshot to irreversibly apply a blur.
- Includes a 3-second auto-upload timer that cancels if the user clicks to blur, and "Upload Now" / "Cancel Capture" buttons.

## 10.5 Instant Clipboard Links
- Updated `POST /upload-url` and `POST /capture` endpoints in the backend to return a 15-minute `readUrl` along with the upload/signed URL.
- If `instantClipboardLinks` is enabled for the user, the `readUrl` is automatically copied to the user's clipboard after a successful capture.
- Uses the `offscreen` document to bypass clipboard restrictions in MV3 service workers.

> [!TIP]
> The extension needs to be reloaded in `chrome://extensions` to pick up these new features, permissions, and the offscreen document. You'll also want to toggle the new feature flags for users in the Admin Portal!
